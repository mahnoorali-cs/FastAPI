# Patient Management API

A simple Patient Management API built using FastAPI and Python.

## Features

- GET patient data
- Create a new patient
- Update patient information
- Delete a patient
- Path parameters
- Query parameters
- Pydantic data validation
- HTTP exceptions
- HTTP status codes
- JSON responses
- BMI calculation

## Technologies

- Python
- FastAPI
- Pydantic
- Uvicorn
- JSON

## Endpoints

- 5 GET endpoints
- 1 POST endpoint
- 1 PUT endpoint
- 1 DELETE endpoint
